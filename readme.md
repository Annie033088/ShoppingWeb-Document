# ShoppingWeb 應用程式 #

## 目錄 ##

2. 還原專案

## 簡介 ##

- 此專案的目的是開發一個網頁版購物網站的後台管理應用程式，專注於提供網站管理功能，讓管理員能夠方便地管理產品、訂單、用戶等資訊。
- 此專案採用 ASP.NET Framework MVC 技術結合 SQL Server 來開發。
